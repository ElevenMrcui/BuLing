## 1. 全局交互约定

| 场景 | 期望行为 |
|---|---|
| 表单提交 | 按钮变 loading · 禁用 · 完成后 toast 反馈 |
| 网络失败 | 全屏 toast + 保留输入 · 提供"重试"按钮 |
| 破坏性动作 | 弹窗二次确认 · 主按钮为"取消" |
| Esc 键 | 关闭 Modal · Popover · Drawer |
| Enter 键 | 在 form 里 = 提交主按钮 |

## 2. 关键交互详述

### 2.1 [交互名]

**触发**：[用户什么动作]

**流程**：
```
用户点击 → 前端立即禁用按钮 → 发起请求
  ↓ 200ms 无响应
显示 loading 指示
  ↓ 响应到
成功 → toast success · 跳转 [页面]
失败 → toast error · 停留原页 · 保留输入
```

**反馈时长**：
- 立即反馈：< 100ms
- 显示 loading 阈值：> 200ms
- 视觉稳定时长（避免闪烁）：≥ 500ms

**边界**：
- 重复点击：忽略（按钮禁用状态）
- 断网重连：自动重试 1 次 · 失败提示手动
- 权限过期：跳登录 · 保留 pending 动作

**无障碍**：
- 键盘：`Enter` 提交 · `Esc` 取消
- 屏幕阅读器：状态变更 aria-live="polite" 广播

## 4. 动效原则（低碳）

- 单动效时长：150-300ms
- 缓动：`cubic-bezier(0.2, 0.8, 0.2, 1)` (类 iOS)
- `prefers-reduced-motion` 尊重：动效全部降到 0.01s
