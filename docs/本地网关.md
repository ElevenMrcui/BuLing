# 不令 · 本地网关（Local Gateway）

> 只做一件事：**在用户 Mac（可扩展至 Linux/Windows）上枚举已安装的 AI 厂商 CLI**，供不令 Web / Artifact 原型在
>「创建 Agent · 技能与模块 · 本机发现」里勾选挂载。

## 1. 为什么需要它

- 浏览器 `fetch` 无法读本机文件系统，也无法执行 `which claude`；
- 又不希望把用户的 CLI 清单 / 版本 / 路径上送到远端服务器（合规友好、离线可用）；
- 所以在用户机器上跑一个**只监听回环**的小守护进程，网页通过 `http://127.0.0.1:17817` 与它对话。

## 2. 强不变量（安全底线，代码级要求）

| 不变量 | 落地 |
|---|---|
| 只监听 127.0.0.1（回环） | `app.listen({ host: '127.0.0.1' })`，网卡上不可达 |
| 每次请求必须带 `X-Gateway-Token` | 全局 `preHandler` 钩子，缺 / 错一律 401 |
| Token 首启自动生成，落 `~/.buling/gateway.token`（chmod 600）| `token.ts` |
| 只读：`command -v` / `fs.access` / 可选 `<cli> --version` | `scan.ts`，不 `spawn` 用户代码，不写任何文件（Token 除外）|
| 不与任何远端服务通信；不发遥测；不加载插件 | 只依赖 `fastify` / `@fastify/cors` |
| CORS 白名单：`null`（file://）+ `*.claude.ai`（Artifact）+ `localhost` / `127.0.0.1` | `main.ts` origin 回调 |
| 版本命令加 3s 超时；失败**返回 null** 而非抛错 | `tryVersion()` |
| `which` 探测的 bin 名走 `/^[a-zA-Z0-9_.-]+$/` 白名单 | `shellQuote()`，防注入 |

## 3. 启动方式

```bash
# 从仓库根
make gateway
# 等价于
pnpm --filter @buling/local-gateway start
```

首次启动会打印 Token；把它连同 Base URL 一起粘到「创建 Agent · 技能与模块 · 本机发现」的配对表单里即可。

```
──────────────────────────────────────────────────────────
不令 · 本地网关已就绪  http://127.0.0.1:17817
──────────────────────────────────────────────────────────
Token （首次生成）: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Token 存放: /Users/you/.buling/gateway.token
──────────────────────────────────────────────────────────
```

生产分发方式（待办）：`pkg` / 单文件二进制 + `launchctl`（macOS）/ `systemd --user`（Linux）。

## 4. HTTP 协议（v0）

所有响应统一 `{ data: ... }` 信封。

### `GET /health`

```json
{ "data": { "status": "ok", "platform": "darwin", "node": "22.x", "supported": true, "registrySize": 10 } }
```

### `GET /discover`

按 `packages/cli-registry` 里的签名逐条 probe，返回：

```json
{
  "data": {
    "items": [
      {
        "id": "anthropic-claude-code",
        "name": "Claude Code",
        "vendor": "Anthropic",
        "category": "agent-cli",
        "description": "...",
        "agentUsage": "...",
        "homepage": "https://...",
        "suggestInstall": "npm i -g @anthropic-ai/claude-code",
        "status": "installed",
        "installedVia": "which",
        "installedPath": "/opt/homebrew/bin/claude",
        "version": "2.1.241 (Claude Code)"
      }
    ],
    "scannedAt": "2026-08-24T04:00:00.000Z",
    "durationMs": 320,
    "platform": "darwin"
  }
}
```

`status` 三态：`installed` / `not-found` / `error`。

### 请求头

必须：`X-Gateway-Token: <token>`；缺 / 错返回 `401`。

## 5. CLI 签名注册表

见 [`packages/cli-registry/src/registry.mac.ts`](../packages/cli-registry/src/registry.mac.ts)。

R1 覆盖：Claude Code / OpenAI Codex CLI / Gemini CLI / OpenAI CLI / Ollama / Aider / GitHub Copilot CLI / Amazon Q Developer CLI / Cursor / LM Studio。

添加新条目的原则：
1. 只列**明确存在**的官方 / 主流工具，宁缺毋滥（不臆造）；
2. `probes` 顺序：先 `which`（PATH 里），再 `/Applications` 的 `.app` 包，最后 Homebrew formula；
3. `agentUsage` 一句话写清「挂到 Agent 上有什么用」，让用户在创建 Agent 时能判断要不要挂载；
4. `suggestInstall` 只写**主流**装法（brew / npm / pipx），不给未审计脚本。

## 6. 前端集成契约

- 原型 / Web 用 `localStorage['buling-gateway'] = { baseUrl, token }` 记住配对；
- 挂载动作：把 `local:<id>` 加进 `draftAgent.modules`，同时把该条目的元数据（name / desc / permission）并入统一 `MODULE_CATALOG`，此后与「已安装」「技能市场」来源走同一套契约；
- **执行侧**：网关只发现不执行；具体调用某个 CLI 的能力，由未来的 API 端 execution 沙箱负责，逐条命令仍需 Agent 权限位放行（`confirmCode` / `confirmExternal`）。

## 7. 平台适配路线

- R1（当前）：macOS 优先，Linux 能启动 + 少量 CLI 命中，Windows 未适配；
- R2：Windows 路径与 probe（`where.exe` / `%LocalAppData%\Programs\...`）、用户自定义 CLI 白名单（`~/.buling/registry.local.yaml`）、pkg 单文件二进制打包与自动升级。

## 8. 未做的事（写下来避免误用）

- 不做 CLI 执行 / 会话代理 / MCP 转发；
- 不做模型接入（那是 API 端的 `providers` 模块）；
- 不做插件机制；
- 不做后台常驻自启（暂交给用户手动 `make gateway`）。
